Aither is a client-side static application intended for trusted internal workflows. Its password checks run in the browser and should not be treated as enterprise-grade access control.

Do not use Aither to store or distribute confidential, regulated, or sensitive information unless you have added appropriate backend authentication, authorization, logging, and data protection controls.
